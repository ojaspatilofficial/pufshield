Test the Defenses

Simulate real attacks to see PUFShield's detection capabilities.

Device Clone
Attempt to replicate a device's PUF identity by copying enrollment data to a different physical device.
Firmware Tampering
Modify firmware payload to bypass integrity checks and inject unauthorized code.
Replay Attack
Reuse a captured authentication challenge to impersonate a legitimate device.
Firmware Rollback
Downgrade to an older, vulnerable firmware version to exploit known weaknesses.
Certificate Forgery
Present an invalid certificate chain that does not trace back to the trusted manufacturer CA.
Wrong Signer
Sign firmware with an unauthorized key to test whether signature validation catches the mismatch.
