LAYER 9 — ATTACK SIMULATION & MONITORING SECURITY TESTING
👾 Device Cloning
Copy cert + key + firmware to new device with different PUF.
✅ Detected: PUF-PKI Binding Mismatch (Stage 3)
⚠ Firmware Tampering
Modify firmware binary payload while keeping signatures.
✅ Detected: SHA-256 Hash Mismatch (Stage 6)
🔄 Replay Attack
Reuse previously captured authentication response.
✅ Detected: Nonce Already Consumed (Stage 5)
📄 Certificate Forgery
Forge certificate using rogue CA, inject into key store.
✅ Detected: X.509 Chain Validation Failure (Stage 4)
↷ Firmware Rollback
Deploy older signed firmware to exploit known vulnerabilities.
✅ Detected: Anti-Rollback Version Policy (Stage 8)
⚠ Wrong Signer
Sign firmware with unauthorized key instead of manufacturer key.
✅ Detected: Manufacturer Signature Failure (Stage 7)
IMPORTANT: All attacks pass through the actual 11-stage boot pipeline. Attacks are NOT independent checks.
