FAILURE REASONS — logged to audit trail before halt

  • Stage 2 — PUF reconstruction failed / enrollment credential mismatch
  • Stage 3 — binding hash mismatch → suspected clone
  • Stage 4 — untrusted CA / expired / malformed certificate chain
  • Stage 5 — invalid signature or replayed (already-consumed) nonce
  • Stage 6 — firmware SHA-256 digest mismatch (tampering)
  • Stage 7 — missing/invalid device or manufacturer signature
  • Stage 8 — firmware version below anti-rollback minimum
